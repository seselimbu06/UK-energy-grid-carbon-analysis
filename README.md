# UK-energy-grid-carbon-analysis
Objective: To analyse historical UK National Grid data to quantify the environmental and economic value of 
industrial load-shifting (shifting energy-intensive processes to off-peak hours)

# Tools Used
Python (Pandas for data manipulation, Matplotlib for graph visualisation)
Google Colab to Code

# Findings
Analysed historical half-hourly data to compare weekday peak hours (16:00 - 21:00) vs. off-peak hours
Found that peak hours have a ~20.7% higher average carbon intensity** than off-peak hours.
- This quantifies the tangible Scope 2 emissions reduction potential for petrochemical and manufacturing plants that implement flexible load-shifting strategies.
